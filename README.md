# 어스토니시아 스토리 (Astonishia Story) — Web

1994년 손노리(Sonnori)의 한국 PC RPG **어스토니시아 스토리**(DOS)를 Lua/LÖVE2D 로
재구현한 비공식 포팅의 love.js 웹 빌드입니다. 학술 / preservation 목적의 비영리
프로젝트이며, 원작자 및 저작권 보유자의 권리를 존중합니다.

▶ Play: https://namyunwoo.github.io/astonishiastory_classic/

- 조작: 방향키 이동 · Enter 결정 · Space 조사/대화 (모바일: 터치 조이스틱 + 키패드)
- 설정 패널: 세이브 다운로드/업로드(IndexedDB 영속), 게임 배속(1.0~3.0×)
- 이 저장소는 빌드 산출물 저장소입니다 (소스/이슈: 링크는 게임 내 개발자노트 참조)
