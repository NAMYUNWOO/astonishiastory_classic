프로젝트 소개

1994년 손노리(Sonnori)가 개발한 한국 PC RPG "어스토니시아 스토리"(DOS)의 원본 바이너리를 분석해 Lua/LÖVE2D 로 재구현하는 비공식 포팅입니다.

현재 상태

  • 오프닝부터 엔딩 스탭롤까지 본편 플레이 가능 — 필드/마을 탐험, 이벤트 컷신, 전투, 상점, 저장/불러오기
  • 원본 DOS 실행 파일의 디스어셈블 분석 + DOSBox 메모리 덤프 대조로 검증한 충실 포팅 (전투 산식·이동 케이던스·컷신 타이밍·PCM/OPL 사운드)
  • 이벤트 컷신 전량 + CG 일러스트(MME) + 마법/이펙트/엔딩 재현
  • 모바일 터치: 화면 드래그 = 이동(가상 조이스틱), 바닥/NPC 탭 = 자동 이동·대화, 메뉴 드래그/탭, 하단 방향키·키패드
  • 게임 배속 1.0~3.0× (설정 → 배속; 사운드 피치는 원본 유지)

알려진 이슈

  • 모바일 브라우저 — Safari/Firefox 보다 Chromium(Chrome) 계열 권장
  • 일부 브라우저에서 BGM 루프 구간이 곡 처음부터 재생으로 대체될 수 있음
  • 세이브는 이 브라우저(IndexedDB)에 저장됩니다 — 기기/브라우저를 옮길 땐 설정 → 세이브파일관리에서 다운로드/업로드를 사용하세요
  • 세이브 이름의 한글 입력(IME)은 데스크톱 키보드 사용을 권장
